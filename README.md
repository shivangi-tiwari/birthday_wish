# 🎂 Happy Birthday Website

A cute birthday website with heartfelt wishes, funny messages, and a puzzle game.

🔗 **Live demo:** https://remarkable-nasturtium-ec9aeb.netlify.app/

## Features
- Sweet birthday wishes
- A puzzle game to play
- Dark mode
- Works on any device

## Built with
TypeScript, Tailwind CSS, Vite

## Run it locally
Run `npm install`, then `npm run dev`.
